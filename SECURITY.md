# Security policy

## Report a vulnerability

Send private reports to [leonid@svyatov.com](mailto:leonid@svyatov.com). Do not disclose an unpatched vulnerability in a public issue.

Include the affected crap4ruby and Ruby versions, a minimal reproduction, and the expected security impact.
Remove credentials and private application data from examples.

Leonid Svyatov monitors this address and will respond within 14 days.
The response will confirm receipt and describe the next investigation step; it does not promise a fix within that period.

## Supported versions

Security fixes target the latest release. Reproduce the issue with that release when possible, but report suspected vulnerabilities in older releases too.
